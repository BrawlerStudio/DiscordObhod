> [!WARNING]

> ### АНТИВИРУСЫ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика.
> Его применяют и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Ряд антивирусов считает файлы WinDivert потенциально рискованными или относит их к хакерским инструментам. Такие файлы удаляются и отправляются в карантин. В названии обнаружения обычно есть `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky предлагает настройку «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». Если вы уверенно умеете настраивать исключения, добавьте их; если не уверены, отключите обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * Chrome: включите «Использовать безопасный DNS» и укажите поставщика, отличный от «Поставщик по умолчанию»
    * Firefox: откройте «DNS через HTTPS», задайте режим «Персональный», выберите «Выбрать провайдера/поставщика» и вручную укажите URL. Например, `https://dns.google/dns-query`: Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить в параметрах самой системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это предпочтительный способ
    * На роутерах Keenetic активируйте параметр «Транзит запросов». Если он выключен, Secure DNS на компьютере может работать неправильно

2. Загрузите ZIP- или RAR-архив со [страницы последнего релиза](https://github.com/BrawlerStudio/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте «Разблокировать». Для архивов, распакованных через 7-Zip или PeaZip, это действие не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллицы и специальных символов

5. Запустите нужный скрипт
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите в **`service.bat`** пункт `Install Service`, затем укажите подходящую стратегию

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - запуск выбранной стратегии вручную

  Ручной запуск позволяет проверить, работают ли стратегии. Результат зависит от множества условий, поэтому **переберите разные варианты (ALT, FAKE и другие), пока не найдёте подходящий**

- [**`service.bat`**](./service.bat) - управление автозапуском и дополнительные инструменты:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - узнать состояние обхода и служб, включая автозапускаемую стратегию и WinDivert
  - **`Game Filter`** - включить или отключить обход для игр и других служб, работающих по UDP и TCP на портах выше 1023.  
  После изменения параметра перезапустите стратегию.  
  В скобках отображается текущее состояние (включено или выключено).
  - **`IPSet Filter`** - управлять применением обхода к сервисам из `ipset-all.txt`.  
  Этот режим пригодится при проверке ресурса, который доступен без zapret, но не работает с ним  
  В скобках показан текущий режим:
    - `none` - ни один IP-адрес не проверяется
    - `loaded` - адрес проверяется на наличие в списке
    - `any` - фильтр применяется к любому IP-адресу  
  - **`Auto-Update Check`** - включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** - подменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - загрузить свежий `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространённые причины сбоев zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает работоспособность приложения
  - **`Run Tests`** - запустить проверку стратегий:
    - `Standard tests` - проверить сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неполадки

### При запуске скрипта `general*` ничего не происходит

- При отдельном запуске стратегии, не через service, должен появиться процесс обхода winws.exe, видимый на панели задач.  
Если процесса нет, ознакомьтесь с [#522](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/522)

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не открывается веб-версия Telegram
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если используемый файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте текст, открытый в блокноте
  - В появившемся каталоге откройте `hosts` текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` (либо замените ранее добавленный аналогичный текст)
  - Сохраните файл и проверьте подключение. Если оно не восстановилось, проверьте, что изменения в `hosts` действительно сохранены.

#### Результат не гарантирован. Если способ не сработал, попробуйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/BrawlerStudio/tg-ws-proxy) или любым публичным.

### Обход не работает или перестал работать

> [!IMPORTANT]
> Стратегии могут со временем перестать работать.
> Иногда обнаружение приводит к тому, что ранее рабочая стратегия больше не помогает.
> В репозитории есть несколько вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из них, изменив параметры.
> Описание параметров стратегий приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте, что адрес нужного ресурса включён в список доменов или IP-адресов

- Переключитесь на другую стратегию, например **`ALT`** или **`FAKE`**

- Попробуйте выполнить полную переустановку (см. ниже)

- Дополнительные сведения: [#765](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сначала сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- В `service.bat` выберите `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные проблемы и в конце введите Y
- Удалите каталог zapret
- Загрузите свежий архив `zapret-discord-youtube-...` со [страницы релизов](https://github.com/BrawlerStudio/zapret-discord-youtube/releases)
- Нажмите на архив правой кнопкой мыши и откройте свойства. Если справа внизу есть пункт «Разблокировать», включите его, затем нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска; не используйте пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если они недоступны, закройте программу (значок замка на панели задач) и попробуйте следующую стратегию
- После выбора подходящей стратегии настройте автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Иначе фильтр может затронуть неожиданные ресурсы.

### Античит выдаёт предупреждение о WinDivert

- Следуйте [этой инструкции](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide)

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится в службах

1. В командной строке Windows (Win+R, `cmd`) узнайте имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив имя из предыдущей команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Попробуйте остальные стратегии, особенно если выбранная раньше перестала работать.
- Обсуждение: [#251](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Для начала определите стратегию, на которой открывается YouTube, и запустите её
- Откройте `service.bat` -> `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если сайт тоже недоступен, переберите стратегии ещё раз: YouTube и Discord могут работать на разных вариантах
- Обсуждение: [#252](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте приложение [tg-ws-proxy](https://github.com/BrawlerStudio/tg-ws-proxy)
- Также можно воспользоваться бесплатными MTProto-прокси из интернета

### Не запускаются игры

Игры различаются, поэтому проверить и устранить проблемы каждой из них невозможно.

Для начала попробуйте универсальный вариант:
- Обновите ipset через `service.bat` и включите `Game Filter`
- Если не помогло, дополнительно включите `ipset any`

Учтите: с параметром `ipset any` многие сайты могут перестать открываться. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если решить проблему не удалось, откройте обсуждение в разделе [Discussions](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions), а не issue, и дождитесь ответа других игроков.

### Не нашли ответ на свой вопрос

- Опишите проблему [здесь](https://github.com/BrawlerStudio/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить перечень адресов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например, когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
